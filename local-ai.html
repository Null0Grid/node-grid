Works with Ollama, LM Studio, LocalAI, llama.cpp server, vLLM, Open WebUI and anything else that speaks the OpenAI chat format, on this PC or anywhere on your network.

Quick start: install Ollama from ollama.com, run ollama run llama3.2 once, then press FIND AUTOMATICALLY.

Another PC on your network? Ollama only listens to its own PC by default; set OLLAMA_HOST=0.0.0.0 on that machine. LM Studio: Developer tab > Start server > "Serve on local network".
